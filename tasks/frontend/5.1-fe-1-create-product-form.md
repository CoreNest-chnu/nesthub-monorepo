# Build product creation form at /admin/products/new

**Complexity**: M | **Areas**: web | **US**: 5.1 — Product creation | **Estimate**: 3h

## Context

Admins need a dedicated UI to create products. The page lives under `apps/web/src/app/admin/products/` (placeholder exists). Submission and redirect are handled in `5.1-fe-2-create-product-submit.md`.

## Granularity note

Frontend-only by design — the BE counterpart is `backend/5.1-be-1-create-product-endpoint.md`. This task is split from the submit logic because the form scaffolding alone is ~3h and reusable across create/edit.

## Scope

**In**:
- New route `apps/web/src/app/admin/products/new/page.tsx`
- Middleware-level admin check redirecting non-admins to `/` (extend existing `apps/web/middleware.ts`; if it doesn't exist, create it)
- Reusable `ProductForm` component (used by edit flow too — see 5.2-fe-1)
- Fields: `name`, `description` (textarea), `price`, `categoryId` (Select), `stock`, `imageUrl` with live image preview
- Zod schema in `apps/web/src/validation/validationSchema.ts` exporting `productFormSchema`
- Categories loaded via existing `useGetCategoriesControllerFindAll()` (or whatever hook Orval generates from `GET /categories`)

**Out**:
- API call / redirect / toast (covered in 5.1-fe-2)
- File upload — image is a URL string

## Acceptance Criteria

- [ ] Route renders only for users with `session.user.role === 'admin'`; non-admins are redirected (verify via middleware); Create (admin) folder with layout check if user admin
- [ ] Form built with `react-hook-form` + `zodResolver(productFormSchema)`, each field wrapped in the existing `Field` component (`apps/web/src/components/Field.tsx`)
- [ ] Category `Select` is populated from the categories API and shows category names; value is the UUID
- [ ] Empty name, non-positive price, negative stock, invalid URL → inline field errors
- [ ] When a valid URL is typed into `imageUrl`, an `<img>` preview appears next to the field (with broken-image fallback)
- [ ] Submit button is disabled while the form is invalid or submitting
- [ ] All visible copy is in English

## Implementation Hints

- shadcn primitives needed — install if missing: `Select`, `Textarea`, `Form` (or keep using existing `Field` wrapper)
  ```bash
  cd apps/web && npx shadcn@latest add select textarea
  ```
- Reference existing form pattern: `apps/web/src/app/(auth)/login/page.tsx`
- Zod schema (English error messages):
  ```ts
  export const productFormSchema = z.object({
    name: z.string().min(1, 'Name is required'),
    description: z.string().optional(),
    price: z.coerce.number().positive('Price must be greater than 0'),
    categoryId: z.string().uuid('Choose a category'),
    stock: z.coerce.number().int().min(0, 'Stock cannot be negative'),
    imageUrl: z.string().url('Must be a valid URL').optional().or(z.literal('')),
  });
  ```
- Live preview: `const imageUrl = useWatch({ control, name: 'imageUrl' })` then render conditionally
- Page layout/spacing: follow whatever shell other authenticated pages under `(protected)` use
