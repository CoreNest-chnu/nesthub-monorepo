# Build category management page /admin/categories

**Complexity**: M | **Areas**: web | **US**: 5.3 — Category management | **Estimate**: 3h

## Context

Single page to list categories, inline-rename them, create new ones, and delete those without products. Pairs with `backend/5.3-be-1-categories-crud.md`.

## Granularity note

Frontend-only by design. Bundles the three operations (list/create/rename/delete) into one task because they share the same view and would be awkward to review separately.

## Scope

**In**:
- New route `apps/web/src/app/admin/categories/page.tsx`
- List of categories with product count (uses existing `GET /categories` extended in BE to include `_count.products`, or a new `GET /admin/categories`)
- Inline rename: click name → input → blur/Enter to save (Esc to cancel)
- "+" button revealing a small create form (single input + submit)
- Delete button per row with shadcn `AlertDialog` confirmation
- Success toasts; on `409 Conflict` from delete, show error toast with the server message (e.g., "Cannot delete category with 3 products")

**Out**:
- Bulk editing
- Sorting / search (small list assumed)

## Acceptance Criteria

- [ ] Page renders only for admins (middleware redirect)
- [ ] List shows each category's name and product count
- [ ] Creating a category appears in the list immediately (cache invalidation)
- [ ] Inline rename updates the row and persists across reload
- [ ] Deleting a category with `count = 0` removes it from the list
- [ ] Deleting a category with `count > 0` keeps the row, dismisses the dialog, and shows an error toast
- [ ] Empty new-category name is blocked with inline validation
- [ ] All copy in English

## Implementation Hints

- shadcn primitives needed — install if missing:
  ```bash
  cd apps/web && npx shadcn@latest add alert-dialog input button
  ```
- Use the Orval-generated mutations: `useAdminCategoriesControllerCreate`, `useAdminCategoriesControllerUpdate`, `useAdminCategoriesControllerRemove`
- Inline edit pattern: a small `<EditableText>` component that toggles between `<span>` and `<Input>` with controlled state and `onBlur` save
- After every mutation success, call `queryClient.invalidateQueries({ queryKey: getGetCategoriesControllerFindAllQueryKey() })`
- Error extraction:
  ```ts
  onError: (err: any) => toast.error(err?.response?.data?.message ?? 'Something went wrong')
  ```
