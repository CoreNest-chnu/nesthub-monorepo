# Create CRUD endpoints for /admin/categories

**Complexity**: M | **Areas**: api | **US**: 5.3 — Category management | **Estimate**: 2h

## Context

Admins need to create, rename, and delete catalog categories. Deleting a category that still has linked products must fail loud — silent cascades would orphan products in the storefront.

## Granularity note

Bundled as a single backend task because the three endpoints share one DTO surface, one controller, and one service. Pairs with `frontend/5.3-fe-1-categories-page.md`.

## Scope

**In**:
- `AdminCategoriesController` with `POST /admin/categories`, `PATCH /admin/categories/:id`, `DELETE /admin/categories/:id`
- `CreateCategoryDto { name: string (NotEmpty) }` and `UpdateCategoryDto` (Partial)
- Delete guard: if the category has linked products (`_count.products > 0`) → throw `ConflictException` (HTTP 409) with the count in the message
- Service-level method per route; reuse existing public `GET /categories` (do not duplicate)

**Out**:
- Bulk operations
- Re-parenting products to another category on delete

## Acceptance Criteria

- [ ] `POST` returns `201` with the created category; empty name → `400`
- [ ] `PATCH` updates the name; unknown id → `404`
- [ ] `DELETE` with no linked products → `204`; with linked products → `409` with payload `{ message: 'Cannot delete category with N products' }`
- [ ] All routes guarded with `JwtAuthGuard` + `RolesGuard` + `@Roles('admin')`
- [ ] Renames propagate: existing products' `category.name` reflects the new value (via Prisma relation, no extra work)
- [ ] Swagger documented so Orval generates the three hooks

## Implementation Hints

- Service deletion check:
  ```ts
  const cat = await this.prisma.category.findUnique({
    where: { id },
    include: { _count: { select: { products: true } } },
  });
  if (!cat) throw new NotFoundException();
  if (cat._count.products > 0) {
    throw new ConflictException(`Cannot delete category with ${cat._count.products} products`);
  }
  await this.prisma.category.delete({ where: { id } });
  ```
