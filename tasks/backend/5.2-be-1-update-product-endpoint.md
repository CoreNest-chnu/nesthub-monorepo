# Create PATCH /admin/products/:id endpoint

**Complexity**: S | **Areas**: api | **US**: 5.2 — Product editing | **Estimate**: 2h

## Context

Admins must be able to update existing products (price, stock, category, copy). Builds on `5.1-be-1` and `5.1-be-2`.

## Granularity note

Backend-only by design. Pairs with `frontend/5.2-fe-1-edit-product-form.md` and `frontend/5.2-fe-2-edit-product-submit.md`.

## Scope

**In**:
- `PATCH /admin/products/:id` route on `AdminProductsController`
- `UpdateProductDto extends PartialType(CreateProductDto)` (from `@nestjs/mapped-types`)
- `AdminProductsService.update(id, dto)` using `prisma.product.update`
- Map Prisma `P2025` "Record to update not found" to `404 NotFoundException`

**Out**:
- Optimistic locking / version field
- Audit log

## Acceptance Criteria

- [ ] `PATCH /admin/products/:id` with partial payload updates only provided fields and returns the updated product
- [ ] Unknown id → `404` with a clear message
- [ ] Invalid field (e.g., `price = -1`, `stock = -3`) → `400` with field-level errors
- [ ] Non-admin → `403`; unauthenticated → `401`
- [ ] Updated fields are reflected in `GET /products/:id` immediately
- [ ] Swagger documents request/response so Orval generates `useAdminProductsControllerUpdate`

## Implementation Hints

- DTO at `apps/api/src/admin/dto/update-product.dto.ts`:
  ```ts
  export class UpdateProductDto extends PartialType(CreateProductDto) {}
  ```
- Catch Prisma error in service:
  ```ts
  try { return await this.prisma.product.update({ where: { id }, data: dto }); }
  catch (e) { if (e.code === 'P2025') throw new NotFoundException('Product not found'); throw e; }
  ```
- Route id param: `@Param('id', ParseUUIDPipe) id: string`
